# 🧮 Calculadora com Tkinter (Python)

Aplicação desktop de calculadora desenvolvida em Python utilizando a biblioteca gráfica Tkinter, com foco em lógica de programação e tratamento de eventos de interface.

## 🚀 Tecnologias Utilizadas
* **Python** (versão 3.x)
* **Tkinter** (Interface Gráfica de Usuário - GUI)

## ✨ Funcionalidades
* Operações matemáticas básicas (adição, subtração, multiplicação e divisão).
* Validação e substituição automática de operadores matemáticos consecutivos.
* Tratamento de exceções para evitar quebras em entradas inválidas.
